# antagon-tracker

# Re:Antagon • Sapnis

Интерактивная презентация и трекер разработки сезона **ANTAGON: REBORN**. Всё собрано в один файл `index.html` в тёмной AMOLED-теме — удобно показывать статус проекта игрокам или записывать промо-ролики прямо с экрана.

Все показатели готовности и этапы внутри презентации будут обновляться регулярно по мере продвижения разработки.

## Сцены и переходы

```
[1. Загрузка] ──▶ [2. Мир и карта] ──▶ [3. Контент и 26.3] ──▶ [4. Медиа]
                                                                    │
                 [7. Финал: 19 дек] ◀── [6. Сводка] ◀── [5. Анонсы] ◀┘
```

| № | Сцена | Что внутри |
| --- | --- | --- |
| 1 | Загрузка | Логотип `Re:Antagon`, кольцо загрузки и плавный переход |
| 2 | Мир | Текстовое вступление, интерактивная SVG-карта с метками `(???)` и параметры мира `5.5k` |
| 3 | Кастомный контент | Статус ядра, переход на `26.3`, прогресс разработки и техадмины (`utophii`, `Fenkovskiy`) |
| 4 | Медиа | Текущий статус и прогресс медиа-направления |
| 5 | Что вас ждёт | Сетка анонсов с авторами (`DmitriySM`, `Tarteen228`, `samicoppersi`, `Marki`) и шкала готовности сервера |
| 6 | Сводка | Три круговых индикатора готовности с быстрым переходом к нужной сцене |
| 7 | Финал | Заголовок **ANTAGON: REBORN**, дата `19 декабря` и кнопка перезапуска |

## Главные фишки

* **Боковой трекер (`re: antagon`)** — синхронизирован со сценами 2–7, показывает текущий этап и позволяет быстро переключаться по слайдам.
* **Удобно для записи видео** — есть автоплей и режим, который прячет все кнопки управления одной клавишей.
* **Адаптивность** — нормально работает и на ПК, и на телефонах (поддерживаются свайпы).
* **Без зависимостей** — карта, переходы и вся логика написаны на чистом HTML/CSS/JS внутри одного файла.

## Управление

| Действие | Клавиши и жесты |
| --- | --- |
| Вперёд / назад | `Space`, `→`, `←`, клик по экрану или свайп |
| Переход к сцене | Цифры `1`–`7` или клик по трекеру |
| Автоплей / пауза | `P` (или `З`) |
| Свернуть трекер | `T` (или `Е`) |
| Скрыть кнопки управления | `H` (или `Р`) |

## Запуск

Сборка и сервер не нужны — просто откройте `index.html` в любом браузере.
